PROBLÈME HISTORIQUE : DEADLOCKS XARRAY
Cause racine :
Incompatibilité xarray + Dask + PyTorch multiprocessing :

xarray crée des Dask arrays (lazy loading)
Dask spawne des threads internes
PyTorch fork() les workers
Threads ne survivent pas au fork() → deadlocks
Solution :
Élimination totale de xarray dans getitem() :
store = zarr.open(str(sst_file), mode='r') # Pure Zarr, NO xarray
patches_t[var_name] = arr[lat_slice, lon_slice] # Direct numpy slice

GradSolver (Orchestrateur)
Variable d'optimisation: STATE (15 channels SST)

CERVEAU 1: BilinReconstructorPriorCost
Rôle: Apprendre à reconstruire SST depuis obs
	Input:  batch.input (139 ch)
	Output: reconstructed SST (15 ch)
Utilisation: Calculer prior_cost(state, batch)= MSE(state, reconstructed)

CERVEAU 2: BaseObsCost
Rôle: Comparer state avec observations réelles
	Input:  state (15 ch), batch.tgt (15 ch)
	Output: observation cost (scalaire)
Utilisation: Calculer obs_cost(state, batch)= MSE(state, batch.tgt) sur non-NaN

CERVEAU 3: ConvLstmGradModel
Rôle: Moduler les gradients intelligemment
	Input:  gradient brut (15 ch)
	Output: gradient modulé (15 ch)
Utilisation: Apprendre la meilleure descente

2. LE CODE ! solver.py:28-48
def solver_step(self, state, batch, step):
    # 1. Calcul du coût TOTAL (prior + obs seulement, PAS de gradient dedans!)
    var_cost = self.prior_cost(state, batch) + self.obs_cost(state, batch)
    # 2. Calcul du GRADIENT de var_cost par rapport à STATE
    grad = torch.autograd.grad(var_cost, state, create_graph=True)[0]
    #      └─ Ceci est ∂(var_cost)/∂state, PAS la sortie du LSTM !
    # 3. Le LSTM prend le gradient en ENTRÉE
    gmod = self.grad_mod(grad)
    #      └─ grad_mod = ConvLstmGradModel
    #         Input:  grad (gradient brut)
    #         Output: gmod (gradient modulé)
    # 4. Mise à jour du STATE (PAS des poids!)
    state_update = (
        1 / (step + 1) * gmod
        + self.lr_grad * (step + 1) / self.n_step * grad)
    return state - state_update
    #      └─ On SOUSTRAIT au STATE, pas aux poids du modèle!
    
    
    
3. Confusions

Confusion 1: "La loss = prior + obs + gradient"        					FAUX !
var_cost = prior_cost + obs_cost  # PAS de gradient dedans!
Le gradient N'EST PAS un terme du var cost. Le gradient est calculé depuis la loss.

Confusion 2: "Tout ça va dans le LSTM" 							FAUX ! 
Le LSTM reçoit SEULEMENT le gradient, pas la loss :
gmod = self.grad_mod(grad)  # Input: gradient, Output: gradient modulé

Confusion 3: "Le LSTM est soustrait AUX POIDS DU MODÈLE"				FAUX ! 
Le LSTM est soustrait au STATE (l'image SST), pas aux poids :
state = state - state_update  # state est l'image SST (15 channels)

Confusion 4: "grad = sortie du LSTM" 							FAUX ! 
grad est l'ENTRÉE du LSTM :
grad = torch.autograd.grad(var_cost, state, ...)[0]  # Gradient calculé
gmod = self.grad_mod(grad)  # gmod = SORTIE du LSTM



4. Les DEUX niveaux d'optimisation (CRUCIAL)
NIVEAU 1 : Optimisation du STATE (dans forward)
	Où : Boucle for step in range(n_step) dans GradSolver.forward() 
	Quoi : On optimise le state (l'image SST) 
	Comment : Gradient descent manuel state = state - gradient
	Variables optimisées : state (B, 15, H, W) - l'image SST 
	Paramètres du modèle : FIXES pendant cette optimisation (grad_mod, prior_cost ont des poids fixes)

NIVEAU 2 : Optimisation des POIDS (backward)
	Où : Après le forward complet, dans base_step() models.py:1041-1109 
	Quoi : On optimise les paramètres des réseaux (BilinReconstructor, ConvLstmGradModel) 
	Comment : Backpropagation classique (Adam optimizer). 
		out = self(batch=sbatch, res=res)  # Forward complet (avec boucle n_step)
		loss = MSE(out, batch.tgt)  # Loss finale
		loss.backward()  # Backprop: calcule ∂loss/∂(poids des réseaux)
		optimizer.step()  # Met à jour les poids
	Variables optimisées : Poids de BilinReconstructor, ConvLstmGradModel, etc.


FORWARD (GradSolver) - Optimisation du state
INITIALISATION:
	state_0 = BilinReconstructor(batch.input) OU fusion slstr+aasti OU autre init (15 channels, pas de leakage)
BOUCLE: for i in range(n_step)  (i = 0, 1, 2, ...)
Itération i -> i+1:
	1. Calcul des coûts:
		reconstructed = BilinReconstructor(batch.input) -> En fait ca pourrait etre autre chose, comme reconstructed = BilinReconstructor(state_{i}). A tester.
		prior_cost = MSE(state_i, reconstructed)
		obs_cost = MSE(state_i, batch.tgt) sur non-NaN
		var_cost = prior_cost + obs_cost 
	2. Calcul du gradient:
		grad = ∂(var_cost)/∂state_i
	3. Modulation par LSTM:
		gmod = ConvLstmGradModel(grad)
	4. Mise à jour du state:
		update = 1/(i+1) * gmod + lr*(i+1)/n_step * grad
		state_{i+1} = state_i - update
RETOUR:
	state_final = state_{n_step}

BACKWARD (PyTorch) - Optimisation des poids des réseaux
1. MSE loss (pixel-wise):
	loss = MSE(state_final, batch.tgt)
	Poids: 1.0
	Mesure: Erreur pixel par pixel (ALL pixels, masqués inclus)
2. Gradient loss (Sobel):
	grad_loss = MSE(sobel(state_final), sobel(batch.tgt))
	Poids: 0.001
	Mesure: Erreur sur les contours/transitions
3. Prior loss (BilinReconstructor seul):
	prior_recon = BilinReconstructor(batch.input)
	prior_loss = MSE(batch.tgt, prior_recon)
	Poids: 0.01
	Mesure: Qualité BilinReconstructor sans itérations
LOSS FINALE:
	training_loss = 1.0 * loss+ 0.001 * grad_loss+ 0.01 * prior_loss

MISE À JOUR:
	training_loss.backward()
	optimizer.step()  <- Met à jour θ (poids des réseaux)
		• BilinReconstructor
		• ConvLstmGradModel
