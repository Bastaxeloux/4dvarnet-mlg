  satellitaire océanographique. J'étudie le papier de Beauchamp et al. (2023)
  "4DVarNet-SSH: end-to-end learning of variational interpolation schemes for
  nadir and wide-swath satellite altimetry".
  Objectif technique :
  4DVarNet combine assimilation de données variationnelle et réseaux de neurones
   pour reconstruire la hauteur de surface de mer (SSH) à partir d'observations
  satellites parses. La méthode utilise un opérateur dynamique Φ appris et un
  solveur LSTM pour optimiser une fonction de coût variationnelle.
  Architecture clé :

  Décomposition multi-échelle : x* = x̄ + dx2 (baseline OI + anomalies apprises)
  État augmenté avec dx1 (observations) et dx2 (reconstruction)
  Solveur gradient-based avec LSTM pour optimisation adaptative
  Loss function combinant reconstruction, gradients, et régularisation physique

  PyTorch Lightning : Framework pour structurer l'entraînement deep learning (je

  Hydra : Gestionnaire de configuration pour les expériences ML (je ne connais

  Architecture résiduelle avec unités bilinéaires
  Données OSSE (Observing System Simulation Experiments) sur NATL60

  Contexte du projet

  Je travaille sur 4DVarNet-SSH (Beauchamp et al. 2023), une méthode deep
  learning pour l'interpolation de données d'altimétrie satellitaire
  océanographique. Le projet utilise PyTorch Lightning + Hydra. Mon niveau :
  bon en maths/physique, faible en PyTorch, novice en Lightning/Hydra.

  Objectif de la session

  Créer un script inference.py pour faire une inférence avec un modèle
  pré-entraîné, visualiser les résultats avant/après prédiction, pour
  apprendre les bases avant d'aller plus loin.

  Ce qu'on a accompli

  1. Résolution des erreurs de chargement du modèle

  Problème initial : GradSolver.__init__() missing 4 required positional
  argumentsSolution : Créé tous les composants requis avec les bonnes
  dimensions (trouvées dans config/params/bigger_model.yaml) :
  - BilinAEPriorCost(dim_in=15, dim_hidden=64)
  - BaseObsCost()
  - ConvLstmGradModel(dim_in=15, dim_hidden=96)
  - GradSolver avec n_step=10

  2. Correction du checkpoint loading

  Problème : Size mismatch entre le code et le checkpoint
  starter_big_mod.ckptSolution : Utilisé dim_hidden=64 (BilinAEPriorCost) et
  dim_hidden=96 (ConvLstmGradModel) au lieu de 48

  Problème : Missing opt_fn keysSolution : Importé cosanneal_lr_adam de
  src.utils et utilisé comme opt_fn

  3. Chargement et exploration des données

  Données : data/natl_gf_w_5nadirs.nc (252MB)
  - Dimensions : (365 jours, 240x240 grille spatiale)
  - Zone : Atlantique Nord (32°-44°N, 54°-66°W)
  - Variables :
    - ssh : SSH vérité terrain complète (target)
    - nadir_obs : Observations satellites parses avec NaN (input)
